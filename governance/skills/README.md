# Skill Governance

This folder answers: **What Brain-owned metadata contract must reusable agent
workflows satisfy?**

- [`skill-metadata.md`](./skill-metadata.md) preserves the ownership metadata model; its
  validator migration is pending. The current writer map and skill bodies own
  operational routing.
- The executable skill definitions live in [`../../skills-hub/`](../../skills-hub/),
  whose README describes the currently installed package checks.

Workflow instructions stay beside their scripts and references in
`skills-hub/`; this folder contains only cross-cutting governance for those
instructions.
