# Operations

This folder answers: **How do people and agents work in this repository?**

- [`repo-workflows.md`](./repo-workflows.md) is the canonical operating contract.
  It classifies work, routes it to the owning surface, defines shared repository
  conventions, and describes common flows.
- [`roles/agent-role-guidance.md`](./roles/agent-role-guidance.md) explains the
  local Creator/Builder interaction setting.

Artifact shapes belong in [`../artifacts/`](../artifacts/), and evidence or gate
rules belong in [`../quality/`](../quality/). Keeping those responsibilities
separate prevents this folder from becoming another flat collection of
unrelated instructions.
